# Example Prompts

## 从零设计

```text
使用 $ui-app-skill，研究真实 iOS 情绪记录和习惯追踪 App，为年轻用户设计首页、记录页、趋势页和个人中心，并生成可交互 HTML 原型。
```

## 工具类 App

```text
使用 $ui-app-skill，先研究 UI Notes 等公开来源中的扫描、文件整理和效率工具，再设计一个 AI 文件整理 App。重点解决首次导入、处理中、失败恢复和历史记录。
```

## 双平台适配

```text
使用 $ui-app-skill，为同一款记账产品分别设计 iOS 和 Android 版本，保留品牌一致性，同时明确导航、返回、选择器和弹窗的差异。
```

## 设计走查

```text
使用 $ui-app-skill 评审这些 App 截图。按 P0–P3 标记视觉、交互、平台规范和无障碍问题，并给出可以直接修改的建议。
```

## 作品集优化

```text
使用 $ui-app-skill 优化这个移动端项目的作品集展示。检查产品逻辑、页面选择、设计说明和排版，避免只做视觉装饰。
```
